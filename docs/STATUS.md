## Сделано (2026-06-12)

### MobileSAM подключён — через ultralytics, без нового пакета
- Установка `pip install git+…MobileSAM` недоступна (политика: код из внешнего GitHub
  не ставим без явного одобрения). Вместо этого `segment.py` использует **встроенную
  реализацию `ultralytics.models.sam`** — это тот же MobileSAM (vit_t), веса
  `mobile_sam.pt` (38.8 МБ, Apache-2.0) докачиваются с CDN ultralytics в `models/`.
- Цепочка бэкендов: пакет `mobile_sam` (если установлен) → `mobile_sam_ultralytics`
  → GrabCut. Эмбеддинг кадра кэшируется (N дефектов = 1 прогон энкодера).
- Фиксы по дороге: `save=False` у SAM-предиктора (иначе ultralytics писал свои
  overlay в `runs/` на каждый кадр); страховка `mask.shape == кадру` как в detect.py.

### Depth Anything V2 Small подключена (`--depth`)
- `transformers` установлен в `.venv`; модель скачалась при первом запуске.
- Проверено на реальном фото: в metric появились `depth_bucket="shallow"` и
  `depth_method="depth_anything_v2_small_relative"`, при этом `depth_cm=null` и
  `depth_certifiable=false` — honest-mode не нарушен.

### Фикс CLI: падение на cp1251 при перенаправлении вывода
- `python -m road_defect.cli … > файл` на русской Windows падал с UnicodeEncodeError
  на символе `→` (cp1251). Теперь stdout/stderr переводятся в `errors="replace"`,
  стрелка заменена на `->`. (Смок-тест не падал случайно: `import ultralytics`
  перенастраивает консоль раньше первого print.)

### Визуальная верификация масок (воркфлоу: 6 агентов, по одному на фото)
- **Маски ям — good на всех 5 ямах**: плотно по контуру, без перелива на целый
  асфальт. Ложных срабатываний нет ни на одном фото.
- ⚠ **Маски трещин — poor на всех 8 трещинах**: SAM заливает bbox целиком или
  выделяет светлый асфальт вокруг тёмной линии. **Корень**: SAM работает на 1024px,
  трещина 1–3 px на 12-МП кадре после даунскейла субпиксельна — модель её физически
  не видит; промптами не лечится. Лечение — классическая экстракция тонких тёмных
  структур (black-hat) в полном разрешении внутри bbox (см. план ниже).
- ⚠ **Люк есть на 3 из 6 фото, но эталоном не подтверждён ни разу** — проверка
  эллипсом слишком строга, масштаб в бою пока не выдавался. Требует разбора
  (но осторожно: ложный масштаб хуже его отсутствия).
- Пропуски детектора: трещины в тени, середины длинных трещин (детекции рвут
  трещину на куски), волосяные трещины.
